# Mywalls — Time of Day Live Wallpaper

Android live wallpaper that changes its sky colours through the day, from sunrise and afternoon to sunset and a starry night.

## Build APK
The GitHub Actions workflow builds a debug APK automatically on every push or when manually started.

After a successful run, open **Actions → Build APK → Artifacts** and download **TimeWallpaper-apk**.

## Project
The Android project is stored in the `TimeWallpaper/` directory.
